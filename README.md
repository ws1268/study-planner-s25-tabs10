# 📚 나만의 공부 시간표 (Flutter Android 앱 + 홈 화면 위젯 + 알림)

정해진 1시간/교시 단위에 얽매이지 않고 **분 단위(예: `09:15 ~ 10:40`)로 자유롭게 시간대를 설정**하고, **지금 해야 할 과목과 세부 할 일(체크리스트)**을 홈 화면 위젯과 실시간 타이머·알림으로 알려주는 모바일 학습 관리 앱입니다.

---

## ✨ 구현된 핵심 기능

1. **분 단위 커스텀 시간 블록 (`StudyBlock`)**
   - 시작 시간과 종료 시간을 1분 단위로 자유롭게 지정 (`-5분`, `-1분`, `+1분`, `+5분` 빠른 미세 조절 버튼 지원)
   - 블록 사이의 쉬는 시간 / 여유 시간 자동 계산 표시
2. **과목별 색상 지정 & 세부 할 일 체크리스트**
   - 과목명 직접 입력 및 빠른 프리셋 칩 + 10가지 테마 색상 지정
   - 공부할 핵심 주제, 메모, 그리고 공부하면서 하나씩 체크할 수 있는 **세부 할 일 체크리스트(`ChecklistItem`)** 지원
3. **요일별 반복 시간표 + 오늘만의 일일 계획 따로 설정**
   - **요일별 기본 시간표**: 월~일 원하는 요일 조합으로 반복 시간표 구성
   - **오늘만 따로 수정 모드**: 평소엔 요일 시간표를 따르다가, 시험 기간이나 특별한 날에는 **[오늘만 따로 수정]** 버튼 하나로 기존 요일 시간표를 건드리지 않고 오늘 일정만 자유롭게 변경 가능
4. **현재 진행 중인 공부 프로그레스 바 / 실시간 카운트다운 타이머**
   - 상단 히어로 카드에서 **지금 해야 할 공부**, **남은 시간(`MM:SS`)**, **실시간 진행률(`%`) 프로그레스 바**, **다음 예정 공부**를 1초 단위로 갱신
5. **시작 정각 알림 & 종료 N분 전 마무리 알림 (사운드 + 팝업 토스트 + 상단 상태바)**
   - Android `flutter_local_notifications` 정확한 시각 알람(`exactAllowWhileIdle`)으로 앱이 꺼져 있어도 시작 정각과 종료 5/10/15분 전에 헤드업 팝업 + 알림음 발생
6. **Android 네이티브 홈 화면 위젯 (`StudyWidgetProvider`)**
   - 스마트폰 바탕화면에 현재 공부 과목, 세부 할 일, 시간대, 진행률 프로그레스 바, 다음 공부 일정을 상시 표시

## 📱 Android 스마트폰용 APK 빌드 방법

### 방법 1: GitHub Actions로 클라우드에서 무료 자동 빌드 (Flutter 미설치 PC 추천)
1. 이 폴더(`study_planner_app`)를 본인의 GitHub 저장소에 업로드(Push)합니다.
2. `.github/workflows/build_apk.yml` 워크플로우가 자동으로 실행되어 **Android 설치 파일(`app-release.apk`)**을 만들어 줍니다.
3. GitHub 저장소의 **Actions** 탭 → 완료된 워크플로우 클릭 → 하단 **Artifacts (`study-planner-release-apk`)**를 다운로드하여 스마트폰에 설치합니다.

### 방법 2: 로컬 PC에서 Flutter로 직접 빌드 및 스마트폰 설치
Flutter SDK가 설치된 환경에서 아래 명령어를 실행합니다:
```bash
cd study_planner_app
flutter create . --project-name study_planner_app --org com.example
flutter pub get
flutter build apk --release
```
빌드된 APK 파일 위치: `build/app/outputs/flutter-apk/app-release.apk`
